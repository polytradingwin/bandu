# 伴读隐私说明

适用于免费自备 API 版 1.0.0，更新于 2026-09-26。

伴读由 Nexwave International Limited 维护。联系：gobacktome123@gmail.com。

## 翻译与第三方

扩展只在启用的网站读取待翻译正文，直接发送到用户配置的 API 地址，并携带该用户的 API Key。伴读不接收密钥或送译正文，不提供翻译中转、付费会员或云端译文缓存。服务商按自己的隐私政策、地域和账户规则处理请求。自定义代理会接收密钥和正文，请先确认可信。

## 本地数据

API 配置和密钥保存在扩展私有 IndexedDB；非密钥设置保存在 chrome.storage.local，不使用 storage.sync。页面内存缓存最多 300 条译文，随页面关闭或设置更新清除。密钥不会发送给网页脚本，但本地存储不代表额外加密，能访问浏览器配置文件的设备用户或软件可能读取数据。

可在 API 设置中删除配置，关闭站点开关、撤销站点权限，或卸载扩展。删除密钥不等于在服务商撤销 API Key，也不会删除服务商已接收的数据。

## 可选 EngBetter 收藏

仅在连接并主动收藏时，所选英文、上下文和来源 URL 发送到 EngBetter。连接凭证保存在扩展私有存储。断开会请求撤销连接，不会删除已有收藏。EngBetter 是独立服务，适用其隐私政策。

## 权限

- storage：本机偏好和非秘密配置。

- activeTab / scripting：用户启用网页的双语展示和可选收藏。

- X / Twitter：默认双语阅读；EngBetter：用户主动授权的连接与收藏。

- 其他网页与 API 地址：用户使用时单独申请权限。API 授权不会自动开启网页翻译。

不申请 history 浏览历史权限，不加载广告或分析脚本，不出售用户数据，不远程下载执行代码。

## 官网与旧账号

bandume.com 提供安装、教程、隐私说明和开源链接。基础托管可能处理 IP、访问时间及请求路径等连接日志。

旧会员版曾保存邮箱、密码哈希、会话、用量、订单及短期译文缓存。免费扩展不再使用旧账号，也不会把旧数据公开。卸载扩展不会删除历史服务器记录；账号删除、历史订单或退款问题请联系上述邮箱。依法需保留的账务与安全记录可能另行保留。
