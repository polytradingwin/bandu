Chrome 应用商店 ↗

免费自备 API 版为 1.0.0。商店更新需要审核，如果商店仍是旧会员版，请使用下方 GitHub 下载，不必购买会员。

下载最新免费版 ZIP ↗ · 查看源码

  1. 下载手动安装包并解压到固定目录。
  2. 打开 chrome://extensions 或 edge://extensions，开启开发者模式，点击“加载已解压的扩展程序”，选择 extension 文件夹。
  3. 固定伴读到工具栏。在 API 设置页选择服务商，填写自己的 API Key、模型和地址，测试并启用。
  4. 打开英文网页，点击伴读开关。其他网站首次使用需要授权。

更新手动安装版后需在扩展管理页重新加载并刷新网页。商店安装版在新版本发布后由商店自动更新。
