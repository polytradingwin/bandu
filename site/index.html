你可能想了解

为什么还要填写 API Key？

伴读负责网页提取与双语排版，模型翻译由你选择的 API 提供。软件免费不代表服务商 API 免费。聊天会员通常不含 API 额度。

官网还需要注册或付费吗？

不需要。官网提供安装、说明和开源链接。旧会员已停止新售卖，历史订单可联系支持查询。

哪些设备可以用？

Windows / macOS 的 Chrome 和 Edge。当前未提供 Safari、iPad 或 Android 正式版，不支持 PDF、图片文字或浏览器内部页面。

EngBetter 必须连接吗？

无需连接。它是独立的可选收藏服务，只在你主动连接并收藏时接收所选内容。
