BRING YOUR OWN KEY

选择服务商，填入自己的密钥。

  1. 在所选服务商官网开通 API，创建自己的 API Key，确认余额和模型权限。
  2. 打开扩展 → API 设置，选择服务商。密钥、接口地域和模型必须对应。
  3. 默认地址可修改。通常填写以 /v1 等路径结尾的 Base URL，不需要附加 /chat/completions。
  4. 勾选数据与费用说明，点击“测试连接并保存启用”，允许访问此 API 地址。
  5. 成功后回到英文网页阅读。测试也会产生 API 调用。

常见服务商

千问、DeepSeek、OpenAI、Gemini、Claude、Kimi、GLM、豆包、硅基流动、MiniMax、百度千帆、腾讯混元、Grok、OpenRouter、Groq、Mistral、Together AI、Fireworks AI、Azure OpenAI。另支持 Ollama、LM Studio 和自定义 OpenAI / Anthropic 兼容接口。

具体模型需以自己账户可用列表为准，不保证所有模型和参数都兼容。模型 ID 可以直接编辑；参数不兼容时可关闭流式或 JSON 模式再测试。

费用与隐私

伴读不收费，API 费用由你与服务商结算。聊天产品的会员通常不等于 API 额度。密钥仅存本机，正文直接发往所填地址，不经伴读转发。服务商故障不会自动切换到另一家。

常见问题

401：检查密钥；403：检查地域、模型权限；402：检查余额；404：检查地址及模型 ID；429：等待限额恢复或检查额度。不要把密钥粘贴到问题反馈或截图中。

本机模型

先在 Ollama 或 LM Studio 启动 API 服务并加载支持中文的模型，再选择对应选项。HTTP 只允许 localhost / 127.0.0.1；远程接口必须使用 HTTPS。
