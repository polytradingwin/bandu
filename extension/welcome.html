伴读 · 免费开源的网页双语阅读扩展

免费使用，自带 API。

无需伴读账号或会员。先在API 设置选择服务商、填写自己的密钥与模型，测试成功即可启用。API 调用费用由你与服务商结算。

从一条推文开始

  1. 在 Chrome 或 Edge 中将伴读固定到工具栏。
  2. 配置并测试自己的 API。
  3. 打开 X，刷新已打开的网页。英文下方会显示中文；继续滚动，新内容会自动翻译。

阅读其他英文网站

打开文章，点击伴读图标 →「双语已关闭」，允许访问当前网站。文章宽屏逐段左右对照，窄屏上下对照；X 始终上下排列。再次点击开关可以移除译文，保留原文。

API 与费用

内置国内外常见服务商及自定义 OpenAI / Anthropic 兼容接口。密钥、地址和模型需属于同一账户地域。聊天会员与 API 账户额度不同。扩展不会自动更换服务商或模型；错误重试与格式修复也可能产生 API 调用。

Ollama / LM Studio 选项需要你先在本机运行模型服务，通常无需密钥。远程接口必须使用 HTTPS。请使用可信的 API 地址。

可选连接 EngBetter

弹窗中的 EngBetter 入口用于连接“我记的日常”。连接后可主动收藏选中的英文；断开连接不会删除已有收藏。EngBetter 是独立服务，不影响伴读翻译。

检查 API 设置、余额、模型权限和网页开关，更新扩展后刷新网页。不支持浏览器内部页面、扩展商店、PDF 或图片文字。Windows / macOS 的 Chrome 和 Edge 可使用同一份扩展；当前未提供 Safari 或手机正式版。
